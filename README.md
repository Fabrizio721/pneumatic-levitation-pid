# Pneumatic Levitation System with PID Control

**Closed-loop control system | MATLAB | Arduino Nano | PID | Sensors | Experimental Validation**

A pneumatic levitation system developed to regulate the vertical position of a lightweight ball using a PID controller.

The project covers the complete control-engineering workflow:

**Mathematical Modelling → Controller Design → MATLAB Simulation → Embedded Implementation → Experimental Tuning → Physical Validation**

Developed as a team project for **Control Engineering I** at Universidad Peruana de Ciencias Aplicadas (UPC).

---

## Project Highlights

- Mathematical modelling of a pneumatic levitation plant
- Classical PID controller design
- MATLAB simulation and frequency-domain analysis
- Routh-Hurwitz stability analysis
- P, PI and PID controller comparison
- Real-time PID implementation on Arduino Nano
- HC-SR04 ultrasonic position feedback
- PWM control of a DC fan through an L298N driver
- Experimental controller tuning
- Physical prototype validation
- Mechanical design using Autodesk Inventor

---

## Physical Prototype

![Physical prototype](images/prototype.jpeg)

The system levitates a polystyrene ball inside a vertical tube using airflow generated by a DC fan.

An **HC-SR04 ultrasonic sensor** measures the ball position continuously.

The Arduino Nano compares the measured position with the desired setpoint and adjusts the fan power through PWM.

## System Architecture

![System block diagram](images/system_block_diagram.jpeg)

The closed-loop architecture is:

**Setpoint → PID Controller → PWM → L298N → DC Fan → Pneumatic Plant → Ball Position → HC-SR04 → Feedback**

The controller continuously corrects the difference between the desired and measured ball position.
